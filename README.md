# Munzeleen Sarwar: Portfolio Website

Personal portfolio website of Munzeleen Sarwar, M.Sc. in Big Data Financial Analytics at Trent University, based in Toronto.

Live site: https://munzeleensarwar.github.io/portfolio/

The site covers her finance projects (each project card links to its GitHub repository), experience as a Business Analyst at DataSense, skills, certifications, and writing and publications with links to the articles.

Built as a single self-contained page in `index.html` and hosted with GitHub Pages.
